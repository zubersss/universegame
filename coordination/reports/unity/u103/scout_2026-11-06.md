## What the code does today
- `SpaceWorld.Build` → `AddSphere` draws every body as a spheroid mesh ("Disc", radius `b.radius` = PlanetConfig.visualRadius)
  with SpaceLit, an atmosphere shell, a cloud shell, a glow sprite (`AddGlow`), and Saturn's rings from `planets/saturn/rings`
  (`AddRings`). `BodyInfo { name, position, radius, gravity, wellFactor, k, landable, isSun, planet, parent }`.
- `SpaceBackdrop` loads `ArtKeys.Backgrounds.Layer("space", i)` for i = 0..2 as camera-filling quads with its own parallax
  factors (0.002 / 0.006 / 0.015) and tilesPerScreenHeight; one draw call per layer.
- `View2D/SceneLayout.Layer` has only `n, parallax, y_m`; `ParallaxLayers` (side view) anchors to a datum and frame height.

## Plan
1. `SceneLayout.Layer` gains `tile, tile_y, height_px, role` (JsonUtility reads them; the side scenes ignore them).
2. `SpaceBackdrop.ConfigureFor("backgrounds/space/starfield")`: load the json (`<key>/json` or read the sidecar through
   Addressables as a TextAsset: check how ParallaxLayers resolves a scene json) and `layer{n}` sprites; layer0 a camera-filling
   quad with Repeat wrap scrolling at parallax 0.05 in x and y (tile_y); layer1..3 as sprites centred on the camera × (1 −
   parallax), drawn behind the bodies (order −200..−197). Keep one draw call per layer. Drop the layer0..2 keys from
   ArtKeys/the importer lists once SpaceBackdrop no longer loads them.
3. Discs: `AddSphere` → `AddDisc`: a SpriteRenderer "Disc" playing the sheet's `idle` clip through the generated sheet
   controller (`Generated/Sheets/planets/<name>/disc/animator.controller`, SheetAnimatorBuilder) stepped at 12 fps; scale so the
   drawn radius equals `b.radius`: sprite radius in units = radius_px / ppu = radius_u, so `localScale = b.radius / radius_u`.
   A wrong `space_ppu` or `radius_u` therefore fails the size assert (D-098) instead of looking wrong. Keep the glow sprite;
   drop the spheroid, atmosphere and cloud shells for converted bodies (SpaceLit stays for the asteroid belt models).
   Moons: `planets/<name>/disc` too (luna radius_u 7). The Sun: `planets/sun/disc` (self-lit).
4. Saturn: `rings_back` (sorting −1) and `rings_front` (+1) around the disc, both at scale `b.radius / radius_u` of the disc;
   wobble on the 110 bpm beat stepped at 12 Hz: `scale.y = 1 ± 0.04·sin`, `rotation = ±1.5°·sin`, pure helper `RingWobble(beats)`
   for an EditMode test. Retire `AddRings` (`planets/saturn/rings`) when both ring sprites resolve.
